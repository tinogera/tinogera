**Plug & Pray** — a distributed operating system simulator written in **C**. Seven independent modules (scheduler, memory with segmentation and swap, CPU, I/O) talk to each other over **TCP sockets**, just like processes on separate machines. Covers process scheduling (FIFO/RR), BEST/WORST FIT allocation, memory compaction and a full fetch–decode–execute cycle with an MMU.
